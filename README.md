# iyf-s11-week-10-kuriarobert41-debug

Week 10 Node.js/Express demo for IYF. This repository contains a minimal Express server and small Node scripts demonstrating built-in modules.

## Run locally

1. Install dependencies:

```
npm install
```

2. Start the server:

```
npm start
```

3. Open in your browser or curl the endpoints:

- http://localhost:3000/
- http://localhost:3000/about
- http://localhost:3000/api/health

Note: The server reads the PORT environment variable (process.env.PORT) so you can run it on a custom port:

```
PORT=4000 npm start
```

## Deploy

Recommended (simple): Render

1. Create a free Render account and connect your GitHub repository.
2. Create a new "Web Service" and pick this repository.
3. Set the build command to `npm install` (or leave blank) and the start command to `node server.js`.
4. Deploy and Render will provide a public URL. Render sets the PORT env var automatically.

Alternative: Heroku

1. Create a Heroku app.
2. Ensure this repo has a `Procfile` (it does: `web: node server.js`) or rely on the `start` script in package.json.
3. Connect the GitHub repo in the Heroku dashboard or `git push heroku main` to deploy.
